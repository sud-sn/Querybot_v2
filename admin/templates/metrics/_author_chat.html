Describe a metric

Say what to calculate — “revenue per active customer”, or paste Net Revenue = SUM(AMOUNT) - SUM(DISCOUNT) FROM DW.SALES_FACT. An explicit definition like that is parsed directly, with no model call. Either way the formula is checked for syntax and column existence, then run against the database to prove it binds — none of which can tell you it is the right calculation. That judgement is yours.
