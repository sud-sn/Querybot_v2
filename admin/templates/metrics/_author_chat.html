Describe a metric

Say what to calculate — “revenue per active customer”, or paste Net Revenue = SUM(AMOUNT) - SUM(DISCOUNT) FROM DW.SALES_FACT. An explicit definition like that is parsed directly, with no model call. Either way it is validated and run against the database before you see it.
