AI prices

US dollars per million tokens, for every workspace

Every AI call (questions, Learn, admin tools) is costed when it is made, from the tokens the provider reports: plain input, input read from the cache, input written to it, and output. A call keeps the cost it was made at, so a new price counts from now on. A model with no price shows no cost rather than a guess; set its price and the calls it already made are costed too.
